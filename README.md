# ML Experiments

A collection of hands-on machine learning experiments built while learning core ML concepts.

## Contents
- **Naive Bayes (Titanic)** — Gaussian Naive Bayes classifier predicting survival, 
  78.2% accuracy. Includes EDA, preprocessing, and evaluation (confusion matrix, F1).
- **Linear/Ridge/Bayesian/Robust Regression** — Comparing regression techniques 
  on a housing-style dataset to study regularization and outlier robustness.
- **Polynomial Regression** — Exploring model complexity (degree 1–10) to visualize 
  the bias-variance tradeoff.

Built with pandas, NumPy, scikit-learn, and Matplotlib/Seaborn.
