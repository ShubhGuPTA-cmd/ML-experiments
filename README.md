## 1. Clustering

Clustering is an unsupervised machine learning technique used to group similar data points based on their characteristics.

### Algorithms

| Algorithm | Description | Real-World Application |
|---|---|---|
| K-Means Clustering | Divides data into K clusters based on similarity. | Customer segmentation |
| Gaussian Mixture Model (GMM) | Uses Gaussian distributions to identify probabilistic clusters. | Pattern recognition |

## 2. Dimensionality Reduction

Dimensionality reduction techniques reduce the number of features in a dataset while preserving important information.

### Algorithms

| Algorithm | Description | Real-World Application |
|---|---|---|
| Principal Component Analysis (PCA) | Transforms data into fewer principal components while retaining maximum variance. | Image compression and visualization |

## 3. Regression

Regression is a supervised machine learning technique used to predict continuous numerical values.

### Algorithms

| Algorithm | Description | Real-World Application |
|---|---|---|
| Linear Regression | Models a linear relationship between input and output variables. | House price prediction |
| Robust Regression | Reduces the influence of outliers on regression results. | Financial data prediction |
| Bayesian Regression | Uses probability distributions to estimate model parameters and predictions. | Risk and uncertainty estimation |
| Ridge Regression | Uses L2 regularization to reduce overfitting and handle multicollinearity. | Sales forecasting |

## 4. Classification

Classification is a supervised machine learning technique used to assign data points to predefined categories or classes.

### Algorithms

| Algorithm | Description | Real-World Application |
|---|---|---|
| Support Vector Machine (SVM) | Finds an optimal decision boundary to separate different classes. | Image classification |
| CART (Classification and Regression Trees) | Uses decision trees to perform classification and regression tasks. | Medical diagnosis |
| Naive Bayes | Uses Bayes' theorem with a conditional independence assumption. | Spam email detection |
| Linear Discriminant Analysis (LDA) | Finds linear combinations of features that separate different classes. | Face recognition |

## 5. Ensemble Learning

Ensemble learning combines multiple machine learning models to improve predictive performance.

### Algorithm

**Two-Tier Stacking Ensemble Learning**

Stacking is an ensemble learning technique in which multiple base models are combined using a meta-model.

- **Tier 1 – Base Models:** Multiple machine learning algorithms generate predictions.
- **Tier 2 – Meta Model:** A second-level model learns from the base models' predictions to produce the final output.

**Applications:**
- Fraud detection
- Medical prediction
- Customer churn prediction
- Credit risk assessment
